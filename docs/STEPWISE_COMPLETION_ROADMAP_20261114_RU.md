## IV. ПОРЯДОК ПРОХОЖДЕНИЯ КАЖДОГО ЭТАПА

1. Создать локальную ветку от чистого `main`; записать входные факты и тест ожиданий.
2. Сначала воспроизвести ошибку тестом, затем исправить её, не изменяя NASA raw JSON и научные утверждения без первоисточника.
3. Проверить Python API, TS build/lint, EN/RU/UZ и браузерные сценарии на ПК.
4. Запустить `D:\AgroSat\check_all.ps1`; любые сбои устраняются до Git-коммита.
5. Зафиксировать результаты, ограничения и ссылку на Git commit/tag в docs, затем объединить ветку с `main`.
6. Публичное размещение, GitHub remote и NASA submission — только в согласованном этапе 8.

*Отдельно: этот план не обещает автоматически выполнить все будущие этапы в фоне. Каждый следующий этап выполняется в очередном интерактивном проходе и завершается своим отчётом PASS.*
