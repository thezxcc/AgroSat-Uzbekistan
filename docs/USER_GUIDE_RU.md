# AgroSat — инструкция на русском

## Что это такое
AgroSat Uzbekistan — исследовательское приложение для задания **Field Shift: Adapting Farms with NASA Data**. Оно показывает, как исторические данные NASA об осадках и температуре и условия конкретного хозяйства помогают сравнивать три варианта севооборота. Оно **не** обещает конкретный урожай или доход.

## Как открыть
1. В PowerShell: `cd D:\AgroSat`
2. Запустить: `.\start_local.ps1`
3. Открыть: **http://127.0.0.1:5173**
4. Справа наверху выбрать язык **Русский** или **O‘zbekcha**. При новом открытии сайта язык снова английский — это сделано специально.
5. Для изучения методов и терминов перейти во вкладку «Методика и источники».

## Как сравнивать
1. Сначала посмотреть исторические осадки NASA за выбранный год. Это данные **региона около Ургенча**, не конкретного поля.
2. Указать доступность воды для полива и уровень засоления. Если неизвестно — выбрать «Неизвестно»: приложение не будет подставлять вымышленные значения.
3. Выбрать цель (вода, дополнительный урожай или почва), примерный срок посева маша и наличие техники.
4. Если есть данные о текущем севообороте, включить соответствующую галочку и описать культуры в поле ввода. Иначе A — лишь **условный базовый вариант**, не текущая фермерская практика.
5. Нажать «Сравнить три варианта». Прочитать для A, B, C преимущества, риски, неопределённости и шесть факторов сравнения.

## Какие три варианта
- A: пшеница → пар → хлопчатник (демонстрационный базовый случай);
- B: пшеница → маш → хлопчатник (исследовательская альтернатива);
- C: пшеница → маш → сидерат → хлопчатник (альтернатива с зелёным удобрением).

Исследования ICARDA/GIZ касаются таких подходов в регионе, но **не доказывают**, что все три схемы одновременно были измерены в одном и том же опыте. Программа не приписывает им недоказанные проценты роста урожая или экономии воды.

## Что означают цифры
- Осадки — оценка по NASA GPM/IMERG, полученная через NASA POWER, мм за указанный год.
- Очень жаркие дни — число суток с максимальной температурой воздуха ≥40 °C.
- Заморозки — число суток с минимальной температурой воздуха ≤0 °C.
- 75-дневное окно — условный срок для сравнения дат посева маша, **не точный прогноз роста** конкретного сорта.
- Если показано «Неизвестно», нужны измерения: ECe почвы, фактический полив, техника, календарь, урожаи и т. д.

## Тестирование (после запуска обоих серверов)
`cd D:\AgroSat`

`.\check_all.ps1`

В конце должно быть сообщение **ALL LOCAL AGROSAT QUALITY GATES: PASS**. Оно относится только к локальной работе. Для сдачи NASA отдельно нужны публичные ссылки и подтверждение отправки проекта.

## Git
Исходный код хранится в локальной ветке `main`. Архивы и `research\` исключены из индекса; GitHub пока **не подключён**. Проверка: `git status`, `git log --oneline -3`.

## Ограничения для презентации
Нельзя говорить, что система знает фактический расход поливной воды, засоление каждого поля, вредителей, прибыль или точную урожайность. Спутниковые данные дают региональные признаки; важные факторы фермер должен уточнить.

## Где искать научные доказательства
Под графиком осадков раскрывается раздел «Источники климатических расчётов»: там ссылки на источники NASA и объяснение, что они **не показывают** реальный полив поля. Под каждым из трёх севооборотов есть раздел «Откуда взяты эти выводы?» с научными ссылками ICARDA и пометкой о непроверенных введённых сведениях. Для пользовательского севооборота программа **не** подменяет доказательства чужими экспериментами.
