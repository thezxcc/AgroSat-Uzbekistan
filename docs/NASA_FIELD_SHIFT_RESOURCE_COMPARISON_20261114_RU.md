## 2. Какие именно NASA-данные реально использованы

### NASA source 1: GPM/IMERG — реально используется численно

- `backend/data/NASA_IMERG_Urgench_2000_2025_DAILY_SOURCE.json`
- NASA POWER Daily API **v2.10.3**, `header.sources=["IMERG"]`, параметр `IMERG_PRECTOT`, мм/сутки, UTC, 2000-01-01 — 2025-12-31.
- Пилотная точка 41.55° N / 60.62° E; 9497 календарных суток, сумма за 2025 год **94.47 мм**.
- Backend выводит годовые, месячные осадки и связывает их с методикой; SHA-256 закреплён в `backend/data/NASA_SOURCES_MANIFEST.json`.
- **Не использован отдельный исходный файл GES DISC GPM_3IMERGDF V07** — происхождение IMERG именно через POWER; не преувеличивать.
- Не измеряет полив по каналам, корневую влагу или ET.

### NASA source 2: NASA POWER / MERRA‑2 — реально используется численно

- `backend/data/NASA_POWER_TEMPERATURE_Urgench_2000_2025_DAILY_SOURCE.json`.
- NASA POWER Daily API **v2.10.3**, `header.sources=["MERRA2","POWER"]`, параметры `T2M_MAX`, `T2M_MIN` (JSON также содержит `T2M`), °C, UTC, 2000–2025.
- Backend вычисляет дни Tmax≥40°C, Tmin≤0°C и исторические 75-дневные окна под условные даты.
- Это **reanalysis/model-derived weather series**, а не измерения температуры датчиком именно на конкретном поле.
- Не строит настоящий прогноз погоды, сорт-специфическую фенологию или испарение растений.

### NASA source 3: MODIS / GIBS — используется как изображение

- `frontend/public/imagery/modis_2025_july.png` и `modis_2025_september.png`.
- В `SatelliteImagery` показано сравнение двух региональных визуализаций; hero показывает июль.
- Нет числового NDVI, облачной/QA маски, сопоставленных полевых границ, статистики изменения растительности. Запрещено делать вывод «NDVI 0.76 / влагообеспеченность 28%» на основе этих PNG.

## 6. ВАЖНОЕ РАЗЛИЧИЕ: технический PASS vs научная достоверность

- `check_all.ps1`: **35 Python-тестов**, **735 проверок переводов**, **7 сценариев / 1065 ссылок reason codes**, 3 Chrome-скрипта и 0 JS ошибок в этих сценариях => **локальный технический PASS**.
- Проверены неизменность NASA JSON, SHA‑256, 9497 дат, отсутствие пропусков в этих двух наборах и корректность отчётов.
- Это **не** полевая валидация почв, засоления, культур, опасности болезней, урожая/рынка, прогнозов или водосбережения.
- Главный текущий научный вывод — **прозрачное сравнение трёх исследовательских вариантов и явная необходимость полевых измерений**, а не рекомендация «выберите C, он лучше».
- У нас уже есть ценность для NASA: понятная связь реальных исторических NASA Earth Data, ограничений фермера и научных свидетельств Хорезма.
